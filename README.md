## 项目简介

《破碎洞窟》是一款 2D 平台解谜游戏。玩家需要探索洞穴，理解环境规则，并通过改变地图方块的连接方式来突破障碍。

## 开发环境

- Unity `2022.3.62f3c1`
- C#
- 目标平台：Windows
