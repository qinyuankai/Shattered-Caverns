# 地图碎片图标方案

使用内置 image_gen 生成，透明背景。每张示意图包含四枚配套碎片及完整地图参照，用于美术选型。尚未切分为游戏 Sprite 或接入拾取逻辑。

## 撕裂羊皮纸

Use case: stylized-concept. Asset type: pixel-art game map-fragment icon concept sheet, transparent background. Create one clean sprite sheet showing a set of FOUR matching torn parchment map fragments and their assembled complete map. Layout: four separate fragments across the upper two-thirds in a tidy 2 by 2 grid, then one complete assembled map centered below at similar scale. The four fragments MUST be the actual four complementary quadrants of ONE rectangular parchment map, with matching irregular torn internal edges and continuous map paths; the assembled map below repeats exactly their combined design. Theme: ancient cave treasure map, warm ochre parchment, dark brown blocky outline, simple dark cave route, small red X destination, tiny blue pool. Authentic low-resolution 16-bit pixel art with large crisp square pixels, limited palette, no antialiasing, no smooth gradients. Icons readable at small game-world pickup-marker size. Flat top-down view, no perspective. Show paper edges with simple pixel clusters and subtle 1-pixel highlights. Large clear spacing, no overlap. Transparent background with genuine alpha, no checkerboard painted into image. NO text, labels, letters, numbers, arrows, decorative UI, pedestal, characters, watermark. These are collectible MAP pieces with geography drawn on them, not landscape terrain tiles.
