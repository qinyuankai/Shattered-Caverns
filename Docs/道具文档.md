# 《破碎洞窟》道具与关卡交互物说明

本文记录目前确定会出现在游戏中的道具和关卡对象，供关卡设计、美术和程序统一理解。这里的「道具」也包括地形、机关、生物和载具。本文描述玩法设计，不代表这些功能已经全部实装。带有「暂定」或「待确认」的内容可在规则确定后更新。

## 一览

| 名称 | 类型 | 主要功能 |
| --- | --- | --- |
| 地图碎片 | 收集物 | 集齐同一区块所需的碎片，解锁该区块供玩家放置 |
| 基础方块 | 实体地形 | 组成地面、平台和墙壁，决定玩家能站在哪里、从哪里通过 |
| 冰面 | 特殊地形 | 暂定降低抓地力，让角色更容易滑行 |
| 蘑菇 | 状态机关 | 使玩家中毒，左右移动输入反转 |
| 致死钟乳石 | 接触陷阱 | 玩家实体碰到尖刺时立即重载当前关卡 |
| 光照花苞 | 光照机关 | 见光展开为三格宽的实体平台，失去光照时闭合 |
| 吸水苔藓 | 降雨机关 | 累计淋雨 3 秒后，由一格高膨胀至六格高 |
| 蒲公英 | 可拾取道具 | 携带后按住上方向可缓降，并借助向上风口升高 |
| 藤蔓 | 攀爬机关 | 竖直时可攀爬，淋雨时沿墙向两端生长 |
| 树洞 | 空间机关（暂定） | 角色从另一个次元重新进入同一区块，与进入前的角色共同影响区块 |
| 冰锥 | 下落陷阱／踏脚点 | 下落时砸中角色会造成伤害，落地后固定并可踩踏 |
| 敌对生物 | 动态障碍 | 对玩家构成威胁，限制通行时机或路线 |
| 弹簧 | 移动机关 | 把玩家弹到普通跳跃难以到达的高度 |
| 矿车与可拼接铁轨 | 载具与路线机关 | 旋转区块以对齐固定在区块上的轨道，让矿车沿接通的线路通行 |

## 地图碎片

- **功能：** 每个碎片都属于一个指定的可活动区块。玩家接触后拾取，同一碎片只计入一次；集齐该区块所需的碎片后，便能在放置模式中选用该区块。所需数量由关卡配置。
- **关卡用途：** 让玩家先探索已有区域，再利用解锁的新区块搭出后续路线。例如，收集散落在不同平台上的碎片，拼出能够跨过断层的区块。
- **建议反馈：** 拾取时让碎片从场景中消失，并提示它属于哪个区块、该区块还差几片。

## 基础方块

- **功能：** 基础方块是有实体碰撞的地形单元。横向排布可以形成地面或平台，竖向排布可以形成墙壁。它作为区块的一部分，随区块移动和旋转。
- **关卡用途：** 定义基础通行空间。区块旋转后，原来的墙可以成为落脚面，原来的平台也可能挡住通道。
- **术语：** 「基础方块」是构成地形的小单元；「区块」是可整体操作的地图结构，一个区块可以包含多个基础方块和机关。

## 冰面

- **暂定功能：** 玩家在冰面上移动时更难立即停下或掉头，离开冰面后回到普通地面的移动规则。
- **关卡用途：** 改变起跳前的助跑和落地后的停步距离。可先用一段安全的冰面让玩家感受滑行，再要求玩家利用滑行通过更长的路段或避开边缘。
- **待确认：** 冰面是只改变刹车和转向，还是也改变最高速度与起跳时的水平速度。

## 蘑菇

- **功能：** 蘑菇占 1×1 格，可穿过。玩家实际碰到蘑菇时进入混乱，左右移动输入反转，待放置区块自动左右镜像。每株蘑菇在本次关卡加载中只触发一次，触发后消失。
- **关卡用途：** 中毒可以是移动挑战，也可以是主动利用的解谜手段。例如，只有镜像后的区块能让通道开口对齐时，玩家需要先触发蘑菇，再放置区块。
- **解除：** 沿用左右颠倒状态的复位规则，掉空回到起点时解除混乱，整关重载时恢复场景初始状态。

## 致死钟乳石

- **功能：** 固定在所属区块上，随区块旋转和镜像。玩家碰到钟乳石时死亡并重载当前关卡。
- **关卡标记：** 春季关卡设计表中的 `x`。

## 光照花苞

- 花心受直射光时向两侧各展开一格，形成 3×1 格的实体平台。闭合的花苞和花茎可穿过，失去光照时平台收起。平台可以与墙体重叠，目标区域有玩家时等待展开。

## 吸水苔藓

- 顶部淋雨累计 3 秒后，从 3×1 格切换为 3×6 格的实体苔阶，底边保持原位。中途被遮挡时暂停累计，膨胀后的体积保留到整关重开。苔阶可以与墙体重叠，目标区域有玩家时等待膨胀。

## 蒲公英

- 玩家接触后自动携带，下落或离开风区时按住上方向可缓降，松开后恢复正常下落。携带者进入向上风口时会自动抬升。
- 掉空回到出生点时清除携带状态，并在出生点补发先前领取的蒲公英。

## 藤蔓

- 竖直藤蔓可在进入范围后攀爬，可悬空摆放，也可只贴在墙的一面或贴在两面。
- 与墙体绑定的藤蔓淋雨时沿墙生长，每侧每端一轮最多延长两格，遇到实体障碍时该侧停下。区块旋转会改变藤蔓朝向和受雨情况。

## 树洞

- **暂定功能：** 角色进入树洞后，相当于从另一个次元重新进入当前地图区块。重新进入的角色与进入树洞前的角色同时存在，并共同影响这个区块。
- **关卡用途：** 让谜题可以围绕两个角色如何共同改变同一区块来设计。
- **待确认：** 进入后角色会发生哪些具体变化（包括是否变大）、两个角色分别如何行动及影响区块，由后续关卡设计决定。

## 冰锥

- **功能：** 冰锥下落时，砸中角色会造成伤害。落地后，冰锥的尖端扎进地面，将冰锥固定在落点；此时玩家可以踩在冰锥顶端。
- **关卡用途：** 玩家先避开正在下落的冰锥，再利用已经固定的冰锥作为台阶。还可以旋转冰锥所在的区块，改变踏脚点的位置，借此到达更高处。
- **待确认：** 冰锥在什么条件下开始下落，以及角色受伤后的处理方式。

## 敌对生物

- **功能：** 在关卡中对玩家构成动态威胁，改变玩家何时、从哪里通过。
- **关卡用途：** 例如让玩家观察生物的活动规律，等待安全时机，或者通过重组区块绕开它。
- **待确认：** 敌对生物如何移动、如何威胁玩家，以及玩家只能躲避，还是也能击退或消灭它。

## 弹簧

- **功能：** 为玩家提供比普通跳跃更强的弹跳，帮助抵达高台或其他难以直接抵达的位置。
- **关卡用途：** 把不同高度的通路串起来。例如先将带有高台的区块接到合适位置，再借弹簧跳上去。
- **待确认：** 弹簧是否踩上即触发；能否朝侧向弹射；区块旋转后，弹射方向是跟随弹簧朝向还是始终向上。

## 矿车与可拼接铁轨

- **功能：** 矿车沿铁轨移动。每段铁轨固定在所属地图区块上，玩家不能单独移动、旋转或放置铁轨，只能通过旋转区块改变铁轨的位置和方向。
- **关卡用途：** 旋转区块，使相邻区块的轨道端点和方向对齐，接通原本断开的路线，改变矿车能够到达的位置。
- **待确认：** 矿车能否载人或运物、如何启动，以及遇到断轨时如何处理。
